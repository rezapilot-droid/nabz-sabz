# داروخانه شبانه‌روزی نبض‌سبز

یک رابط کاربری کامل، واکنش‌گرا و فارسی برای داروخانه آنلاین و سامانه مشاوره پزشکی ۲۴ ساعته.

## قابلیت‌های پیاده‌سازی‌شده

- طراحی راست‌به‌چپ با فونت فارسی Vazirmatn
- صفحه اول حرفه‌ای، جستجوی محصول و دسته‌بندی هوشمند
- کارت‌های محصول، فیلتر، علاقه‌مندی، مشاهده سریع و نمایش بیشتر
- سبد خرید پویا با افزایش/کاهش تعداد و محاسبه مبلغ
- آپلود نسخه پزشک در پنجره اختصاصی
- دستیار گفت‌وگوی مشاوره پزشکی ۲۴ ساعته
- انتخاب موقعیت و نزدیک‌ترین شعبه
- بخش پزشکان، کمپین‌های فروش، مجله سلامت و اپلیکیشن
- پیام‌های تعاملی، انیمیشن‌های ظریف و طراحی کاملاً واکنش‌گرا
- تصاویر بهینه‌شده و آیکون‌های Lucide

## اجرای پروژه

```bash
npm install
npm run dev
```

نسخه نهایی:

```bash
npm run build
npm run preview
```

## فناوری‌ها

React، Vite، Lucide React و CSS سفارشی.
