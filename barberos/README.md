# باربر OS (BarberOS) — نسخه‌ی PWA/Webapp

پیاده‌سازی MVP وب‌اپلیکیشن «آرایشگاه مردانه» مطابق سند
[`BarberOS-Workflow-v2.0.md`](../BarberOS-Workflow-v2.0.md).

## اجرا

```bash
cd barberos
npm install
npm run dev        # توسعه — http://localhost:5173
npm run build      # بیلد نهایی (PWA)
npm run preview    # پیش‌نمایش نسخه‌ی بیلدشده
```

## چه چیزهایی پیاده شده؟

### سمت مشتری (PWA)
- انتخاب خدمت → انتخاب آرایشگر → **تقویم شمسی (جلالی)** → انتخاب ساعت آزاد → ثبت نوبت
- روزهای جمعه و گذشته غیرفعال؛ اسلات‌ها با توجه به ساعات کاری، بافر و نوبت‌های موجود محاسبه می‌شوند
- «نوبت‌های من» با جستجوی شماره موبایل + لغو نوبت
- PWA قابل نصب (manifest + Service Worker + آیکون)

### پنل مدیریت (مالک)
- **داشبورد:** KPI روز (نوبت‌ها، درآمد، اسلات خالی، در انتظار تأیید، در معرض ریزش، مشتریان جدید) + پیشنهادهای عملی (Top Actions)
- **نوبت‌ها:** ماشین حالت کامل (تأیید / حضور / شروع / تکمیل / لغو / عدم حضور) + رزرو دستی
- **مشتریان (CRM):** سطح `tier` (VIP) و `lifecycle` (new/active/at_risk/inactive/churned)، امتیاز ریزش، میانگین فاصله‌ی مراجعات، ترجیحات، تاریخچه
- **خدمات و آرایشگران:** افزودن/ویرایش/حذف + مهارت‌های هر آرایشگر
- **تنظیمات:** اطلاعات کسب‌وکار، ساعات کاری روزانه، سیاست رزرو و سیاست مشتری + بازنشانی داده

### فنی
- داده در `localStorage` ذخیره می‌شود (seed نمونه‌ای زنده نسبت به تاریخ امروز)
- موتور تقویم جلالی دستی (الگوریتم jalaali-js) — تست‌شده
- فرمول Risk Score مطابق سند: `(elapsed − median) / median`
- React 18 + Vite 6 + فونت وزیرمتن + Lucide + تم تیره‌ی طلایی RTL

## ساختار

```
src/
  lib/          jalali.js (تقویم)، format.js، risk.js (موتور ریزش)، seed.js، store.jsx (State + منطق)
  components/   ui.jsx (دکمه/کارت/مودال/Toast)
  views/        BookingFlow، Home، MyAppointments، admin/*
```
